How this machine is built from this repository. Every step can be re-run
to reset a drifted machine; only steps 1 and 2 need a person. The Windows
user is sonta and every path below assumes it.

1. Accounts: C:\data\accounts.txt, written by hand, never committed. Every
   entry is a label line followed by the value on the next line; the
   recovery codes are the one block entry and come last. Labels, in order:
     Email:
     Email password:
     GitHub user:
     GitHub password:
     GitHub token:
     GitHub token scopes:
     GitHub SSH key:
     GitHub TOTP secret:
     GitHub TOTP parameters:
     GitHub recovery codes:
   The token needs the scopes repo, workflow and read:org. Scripts read a
   value with
     $lines = Get-Content C:\data\accounts.txt
     $i = [array]::IndexOf($lines, "GitHub token:")
     $value = $lines[$i + 1].Trim()

2. Done once, interactively: Windows autologon (Sysinternals Autologon:
   Autologon64.exe /accepteula sonta LAPTOP-UNAIQSPV <Windows password>),
   Claude Code login (run claude once and log in), Brave logged in to
   claude.ai (check_usage.ps1 reads the usage page from the default Brave
   profile). Display 1920x1080 at 150% scaling (check_usage.ps1 crops a
   fixed rectangle of the screenshot).

3. Tools, each at its default install path:
     winget install Git.Git
     winget install GitHub.cli
     winget install Brave.Brave
     winget install Notepad++.Notepad++
     winget install UB-Mannheim.TesseractOCR
     JDK 26 at C:\Program Files\Java\jdk-26.0.2, no JAVA_HOME
     irm https://claude.ai/install.ps1 | iex
       (claude.exe lands in %USERPROFILE%\.local\bin, which is on PATH)
     git config --global user.name marcoautomation2
     git config --global user.email marcoautomation2@outlook.com
   Eclipse at C:\data\tools\eclipse, for EclipsePlugin work.

4. This repository:
     git clone https://github.com/marcoautomation2/AgentsCoordination C:\data\AgentsCoordination
     git -C C:\data\AgentsCoordination remote add upstream https://github.com/MarcoServetto/AgentsCoordination
   Reset it with
     git -C C:\data\AgentsCoordination fetch upstream main
     git -C C:\data\AgentsCoordination reset --hard upstream/main

5. Claude Code reads its instructions and skills from %USERPROFILE%\.claude.
   Both point into the checkout, so resetting the checkout resets them:
     New-Item -ItemType SymbolicLink -Path $HOME\.claude\CLAUDE.md -Target C:\data\AgentsCoordination\CLAUDE.md -Force
     New-Item -ItemType Junction -Path $HOME\.claude\skills -Target C:\data\AgentsCoordination\skills -Force
   $HOME\.claude\settings.json is a plain file (Claude Code rewrites it):
     {
       "env": { "EDITOR": "notepad" },
       "permissions": { "defaultMode": "bypassPermissions" },
       "model": "sonnet",
       "autoUpdatesChannel": "latest",
       "skipDangerousModePermissionPrompt": true,
       "theme": "light",
       "agentPushNotifEnabled": true,
       "crossSessionInbound": "accept"
     }
   crossSessionInbound is what lets agent-supervisor.ps1 deliver the
   scheduled messages into a running agent.

6. Agent folders. C:\data\fearlessBranch1, C:\data\fearlessBranch2 and
   C:\data\fearlessBranch3 each hold the seven repositories, cloned from
   the marcoautomation2 fork (origin) with upstream set to the parent:
     foreach ($r in 'Commons','Frontend','Coordinator','StandardLibrary','EclipsePlugin'){ git clone https://github.com/marcoautomation2/$r; git -C $r remote add upstream https://github.com/FearlessLang/$r }
     foreach ($r in 'ZeroToHero','FearlessTour'){ git clone https://github.com/marcoautomation2/$r; git -C $r remote add upstream https://github.com/MarcoServetto/$r }
   plus Coordinator\test\mainCoordinator\LocalResources.java: a copy of
   LocalResourcesTemplate.java from the same folder with the class renamed
   to LocalResources and
     private static Path prefix= Path.of("C:\\").resolve("data","fearlessBranchN");
   Then run the align-branches skill in each folder.
   C:\data\winCoordinator holds only logs\diagnostic.log, written by
   cleanup-watchdog.ps1.
   Each of the four folders has a CLAUDE.md holding the single line given in
   the "Shared memory and shared CLAUDE.md" section of CLAUDE.md, and
   $HOME\.claude\projects\<slug>\memory\MEMORY.md holds that section's
   single memory line, where <slug> is the folder path with every \ and :
   replaced by - (C--data-fearlessBranch1, C--data-fearlessBranch2,
   C--data-fearlessBranch3, C--data-winCoordinator).

7. Startup. One scheduled task, at logon, no time limit, highest run level,
   runs autoScripts\agent-supervisor.ps1: it starts the four agents and
   then, for the rest of the boot, delivers each line of
   autoScripts\scheduledTasks.txt at its time and runs
   autoScripts\cleanup-watchdog.ps1 hourly. There is no other task.
     Register-ScheduledTask -TaskName ClaudeAgentSupervisor -Force `
       -Action (New-ScheduledTaskAction -Execute powershell.exe -Argument '-NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -File C:\data\AgentsCoordination\autoScripts\agent-supervisor.ps1') `
       -Trigger (New-ScheduledTaskTrigger -AtLogOn -User sonta) `
       -Principal (New-ScheduledTaskPrincipal -UserId sonta -LogonType Interactive -RunLevel Highest) `
       -Settings (New-ScheduledTaskSettingsSet -ExecutionTimeLimit (New-TimeSpan) -MultipleInstances IgnoreNew -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries)

8. Check: reboot. Within a few minutes four claude.exe processes run, one
   per agent folder, and Get-ScheduledTask ClaudeAgentSupervisor reports
   Running.
